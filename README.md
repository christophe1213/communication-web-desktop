# Prototype QR + WebSocket (customTkinter ↔ React)

## Installation

```bash
pip install customtkinter "qrcode[pil]" fastapi "uvicorn[standard]"
```

cd frontend
# remplace src/App.jsx par celui fourni
npm install
npm run build        # génère frontend/dist, servi par le desktop
```

## Lancer

```bash
python desktop_app.py
```
